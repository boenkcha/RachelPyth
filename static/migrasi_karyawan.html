Halaman ini mengimpor data dari file Karyawan.csv ke tabel Karyawan pada database sistem baru. Kolom HP dipetakan sebagai telp (nomor handphone diutamakan). Kolom Alamat, T_lahir, Telepon, Tahun_masuk tidak ada di skema baru dan akan dilewati otomatis. Nilai HP --- atau - dikonversi menjadi kosong. File mendukung format koma (,) maupun pipa (|). Pada mode Tambah, karyawan dengan kode yang sudah ada di database akan dilewati.

🔗 Integrasi dengan Tabel Lain
💰
Point_karyawan — Data komisi perawat & beautician menyimpan kd_karyawan. Setelah migrasi karyawan, laporan komisi akan menampilkan nama karyawan lengkap via JOIN. Pastikan nilai kd_karyawan di kedua tabel konsisten (misal: RY, DW).
🧾
R_Penjualan — Setiap detail transaksi menyimpan kd_karyawan perawat yang menangani. Migrasi karyawan membuat laporan treatment & komisi per karyawan bekerja dengan benar.
👥
Pengguna (akun login) — Setiap akun pengguna memiliki field kd_karyawan untuk menghubungkan login dengan data karyawan. Setelah migrasi, buka Manajemen Pengguna dan isi field Karyawan pada setiap akun yang sesuai.
